# Media del cliente

Foto, screenshot e clip usati nel video. Nomi brevi e descrittivi (`taglio-barba.jpg`, `home-sito.png`).

- Foto: almeno 1920 px sul lato lungo. Le scene le ritagliano con `object-fit: cover`, quindi tieni il soggetto al centro.
- Screenshot di siti: catturali a 2x dalla pagina vera (non ricostruiti a mano), senza dati personali o di clienti.
- Persone riconoscibili: solo con il consenso della persona ritratta.
